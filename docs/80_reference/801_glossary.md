# Glossary

**Absent:** A reviewer's decision that the pattern is not supported in an
adequately inspected unit. It is not a missing annotation.

**Analysis unit:** The bounded text or audiovisual span to which an annotation
applies.

**Annotation:** A versioned decision linking one pattern to one work and unit,
with evidence, rationale, reviewer, and lifecycle metadata.

**Audience response:** An actual response by a defined audience under defined
conditions. The current pattern rows do not measure this.

**Authorial intention:** An author's intended meaning or effect. Presence of a
pattern does not establish intention.

**Borderline case:** A case that requires adjudication because a definition or
boundary rule does not settle it.

**Common false positive:** A surface cue that suggests a pattern but fails one or
more required criteria.

**Cross-media analogue:** A proposed realisation of a similar narrative or
formal function in another medium. It is a hypothesis unless tested.

**Drafted:** Coding materials exist, but no pilot has been run.

**Evidence locator:** A stable reference to a quotation, passage, description,
timestamp span, or knowledge state.

**Hard negative:** A realistic case that contains misleading surface cues but is
not an instance of the pattern.

**Indicator:** A potential observable cue that supports consideration of a
pattern. An indicator is not automatically sufficient evidence.

**Interpreted effect:** A plausible effect invited by a representation. It is not
a measured audience response.

**Label type:** The controlled family describing the kind of pattern, such as
`narrative_structure` or `audiovisual_expression`.

**Pattern version:** The version of a specific definition and its criteria.

**Pilot tested:** A recorded pilot has been completed. It does not by itself mean
validated.

**Presence:** A reviewer's decision that the criteria for a pattern are supported
in the unit.

**Proposed:** A candidate definition or rule that has not been tested against a
labelled corpus.

**Schema version:** The version of the annotation data contract.

**Validated:** A fixed validation protocol has been completed and reviewed for
the defined scope. The term must always include that scope.
